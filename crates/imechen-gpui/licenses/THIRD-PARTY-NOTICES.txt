Linux) and .github/actions/libheif/action.yml (Windows, via vcpkg) of the
imechen source repository:

  https://github.com/manomekun/imechen

Replacing the libraries
-----------------------

You may modify these libraries and relink imechen against your modified
versions. The complete source of imechen is available at the repository
above. To rebuild with your own libheif/libde265:

  1. Build them as static libraries into a directory PREFIX, for example by
     editing the source URLs in scripts/build-libheif.sh and running
     `scripts/build-libheif.sh PREFIX`.
  2. Build imechen against them:
       PKG_CONFIG_PATH=PREFIX/lib/pkgconfig SYSTEM_DEPS_LIBHEIF_LINK=static \
         cargo build --release -p imechen-gpui
     On Windows, install them with vcpkg and set VCPKG_ROOT and
     VCPKGRS_TRIPLET=x64-windows-static-md instead.
